# Roadmap 🗺

## ✅ v0.1 — MVP (Done)
- [x] Battle engine with turn-based combat
- [x] SDK with Bot base class
- [x] FastAPI server with submit/match/leaderboard
- [x] React frontend with editor
- [x] ELO matchmaking
- [x] 3 example bots
- [x] Sandbox for safe execution
- [x] Docker support
- [x] CI pipeline
- [x] Comprehensive docs

## 🚧 v0.2 — Live Battles
- [ ] WebSocket support for real-time battle streaming
- [ ] Canvas-based battle animation (replay viewer)
- [ ] Step-by-step replay controls (play/pause/rewind)
- [ ] Bot-vs-bot match browser
- [ ] Spectator mode

## 🚧 v0.3 — Polish
- [ ] PostgreSQL persistence (replace in-memory)

- [ ] Bot versioning (push updates without losing rank)
- [ ] Daily/weekly tournaments with prizes

- [ ] Capture the flag
